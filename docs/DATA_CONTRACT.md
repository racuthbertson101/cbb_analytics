# Data contract v1

All files are JSON under `web/public/data/` (generated by `python -m pipeline.export.contract`, gitignored). The site fetches them client-side through `dataUrl()` (respects `basePath`). Seasons are named by the ending year (2026 = 2025-26). Team/game IDs are ESPN IDs (strings).

| File | Contents |
|---|---|
| `meta.json` | version, current_season, upcoming_season, seasons[], last_game_date, default_asof, current_last_date, season_first_date, generated |
| `teams.json` | teams[]: id, name, short, abbr, loc, color, alt, logo, conf{season: conference name} (all teams that were D-I in 2010+) |
| `games/<season>.json` | games[]: id, d (date), a (away id), h (home id), as/hs (scores or null), n (neutral), t (game type), cg (conference game), ok (completed), pm (predicted home margin), pp (predicted possessions), p (home win prob), plo/phi (80% interval on p), ph/pa (predicted home/away score), ar/hr (AP rank if top 25), d1 (both D-I), note |
| `ratings/<season>.json` | dates[], teams[], off[date][team], def[..], tempo[..], gp[..]: adjusted ratings as of each game date (fit on games strictly before the date; last row = end of season) |
| `ratings/2027_preseason.json` | preseason prior ratings for the upcoming season |
| `rankings/<season>.json` | final table: id, conf, w, l, cw, cl, off, def, tempo, margin, sos, luck |
| `teamstats/<season>.json` | rows{team_id: efg, tov, orb, ftr, (each _d for defense), three_rate, ft_pct, two_pct, three_pct, poss_pg} |
| `params/*.json` | fitted parameters and backtest evidence rendered on the Methodology page |
| `tournament.json` | placeholder `{status: coming_soon}` |

Sharding: per season for games/ratings/teamstats (0.3-3 MB each). Player and game-detail shards are added in later phases (`players/<season>/...`, `box/<season>/<game>.json`). Size budget: whole site < 800 MB.
